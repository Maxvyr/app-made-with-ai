# SaaSify - Next.js SaaS Marketing Template

A modern, responsive SaaS marketing template built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🚀 Built with Next.js 14 and App Router
- 💪 TypeScript for type safety
- 🎨 Tailwind CSS for styling
- 🖌️ Beautiful UI components
- 📱 Fully responsive design
- 🔍 SEO optimized
- 🌙 Light and dark mode support
- 🧩 Modular and customizable components

## Pages

- 🏠 Home page with hero section, features, testimonials, and pricing
- 📝 About page
- 🛠️ Features page
- 💰 Pricing page
- 📞 Contact page

## Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn

### Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/saas-marketing-template.git
cd saas-marketing-template
```

2. Install dependencies:

```bash
npm install
# or
pnpm install
```

3. Run the development server:

```bash
npm run dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Customization

### Branding

- Update the logo and brand name in `src/components/layout/header.tsx` and `src/components/layout/footer.tsx`
- Modify the color scheme in `src/app/globals.css`

### Content

- Update the content in the various section components in `src/components/sections/`
- Modify the pages in `src/app/`

### Images

- Replace the placeholder images in the `public` directory with your own images
