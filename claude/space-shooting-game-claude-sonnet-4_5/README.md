# Space Shooting Game

A classic space shooter game built with React, TypeScript, and HTML5 Canvas.

## Features

- Player-controlled spaceship with keyboard controls
- Enemy ships with AI patterns
- Bullet shooting mechanics
- Collision detection
- Score tracking
- Game states (start, playing, game over)
- Responsive canvas-based gameplay

## Controls

- **Arrow Keys / WASD**: Move the spaceship
- **Spacebar**: Shoot bullets
- **Enter**: Start game / Restart after game over
- **P**: Pause game

## Tech Stack

- React 18.3.1
- TypeScript 5.6.3
- Vite 6.0.1
- Tailwind CSS 3.4.15
- HTML5 Canvas API

## Getting Started

### Prerequisites

- Node.js 16+ (18+ recommended)
- pnpm (preferred) or npm

### Installation

```bash
# Install dependencies
pnpm install
# or
npm install
```

### Development

```bash
# Start development server
pnpm dev
# or
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

```bash
# Build for production
pnpm build
# or
npm run build

# Preview production build
pnpm preview
# or
npm run preview
```

## Game Mechanics

- **Player Ship**: Controlled by keyboard, shoots bullets upward
- **Enemy Ships**: Spawn at the top and move downward with varying patterns
- **Bullets**: Player bullets move upward, destroy enemies on collision
- **Scoring**: Earn points for each enemy destroyed
- **Health**: Player has 3 lives, loses one when hit by enemy
- **Game Over**: Game ends when all lives are lost
